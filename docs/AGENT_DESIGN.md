# Agent design

The live runtime agent uses `@anthropic-ai/claude-agent-sdk` and `query()`. It receives a custom system prompt requiring evidence/inference separation and structured draft output. SDK `tools` is an empty array, `strictMcpConfig` is enabled, settings sources are disabled, and the only auto-approved capabilities are these MCP tools:

- `list_research_sources`
- `discover_products`
- `collect_products`
- `get_product_details`
- `get_research_candidates`
- `get_research_criteria`

All tools use Zod schemas and execute in-process. `discover_products` makes one bounded provider Messages-compatible Web Search request at a time (two searches maximum per job), validates public HTTPS result URLs, and returns only observed title/snippet/price evidence. Direct Anthropic mode uses `web_search_20250305`; OpenRouter mode uses its `openrouter:web_search` server tool through the Anthropic-compatible endpoint. It never grants the agent arbitrary URL navigation. The tools scope reads and collection to the active job's approved source IDs, input niche, optional bounded search phrase, candidate limit, price range, cancellation signal, and duplicate-action limit. Product detail access accepts an already discovered identifier, not an arbitrary URL. Recoverable failures return structured `isError` results without raw exceptions.

The agent must first read criteria and sources, collect an approved batch, inspect evidence, and return a structured completion/partial report. The report is rejected if it cites a product not collected for the job. Its narrative is supplemental only: deterministic scoring never accepts model-generated score values.

`maxTurns`, `maxBudgetUsd`, timeout abort, estimated result cost, and tool-action fingerprints form separate boundaries. See the official [quickstart](https://code.claude.com/docs/en/agent-sdk/quickstart), [custom tools guide](https://code.claude.com/docs/en/agent-sdk/custom-tools), [structured outputs guide](https://code.claude.com/docs/en/agent-sdk/structured-outputs), and [cost tracking guide](https://code.claude.com/docs/en/agent-sdk/cost-tracking).

Repeated collection calls that add no new candidates are independently bounded by `AGENT_NO_PROGRESS_ACTION_LIMIT`; the agent aborts with `AGENT_NO_PROGRESS` after the limit. Caller cancellation is `cancelled`; timeout, no-progress, turn, budget, and execution errors are `failed`. SDK initialization, observable API response, terminal result, structured-output receipt/validation, and tool start/completion/failure events are persisted for the dashboard timeline. Browser failures retain a safe category such as `BROWSER_LAUNCH_FAILED` without exposing raw process output. `total_cost_usd` is displayed as an SDK estimate only after a live result arrives; fixture runs accurately show zero API cost.

Verification boundary: this repository has locally verified the SDK request shape and MCP tool implementations with deterministic tests. A bounded authenticated live run also completed the full path: Anthropic responded, five approved tools registered, `collect_products` collected two products, structured output validated, and a `claude_agent` report persisted in 18.3 seconds at an estimated $0.0305. The Playwright launcher receiver-binding regression is fixed and covered. The only remaining verification step is one manual dashboard-triggered live request; it is not run automatically because it incurs API cost.

`npm.cmd run smoke:live` is the explicit catalog-path verification command. It loads `.env.local` with `@next/env`, refuses without `RESEARCH_MODE=live` and the credential for the selected provider, uses the real worker/SDK path, and accepts success only if the persisted result is a `claude_agent` report with collected products, validated structured output, and a logged `collect_products` MCP completion. `npm.cmd run smoke:openrouter` explicitly refuses unless `AI_PROVIDER=openrouter`; it exercises the same Agent SDK/worker path with one bounded dynamic Web Search discovery request. Its sanitized summary identifies SDK initialization, observable provider response, each MCP tool outcome, output-validation/persistence status, terminal status, cost, duration, and the safe failure category. Its fixed upper bounds are five turns, $0.10 estimated budget, 90 seconds, one page, one Web Search request, and one dynamic discovery candidate. There is deliberately no automatic whole-agent retry setting: rerunning an API agent could multiply cost; recoverable tool errors are instead returned to the bounded agent for a different approved action.

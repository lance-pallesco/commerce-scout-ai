# Roadmap

## Implemented

- Local fixture and bounded Playwright collection adapters
- Claude Agent SDK orchestration with restricted in-process MCP tools
- Deterministic evidence scoring and persisted reports
- SQLite local worker, cancellation, actions/events, CSV export, dashboard, and test suite

## Deferred

1. Authentication, authorization, rate limits, and a managed job queue for deployment
2. Authorized Shopify catalog, CSV-import, and research API adapters
3. Approved advertising-intelligence integrations with credentials and terms review
4. Research scheduling, notifications, and multi-user project collaboration
5. Competitor evidence, landing-page drafts, and Google Ads drafts gated by human approval
6. Distributed worker/storage architecture and production observability

Deferred work is not currently exposed as a completed capability.
